# Contributors

Contributions are welcome! This project is an open-source macOS control utility for
Gigabyte AORUS monitors built on a reverse-engineered Realtek HID protocol.

## How to contribute

- **Pull requests are welcome.** Fork the repo, make your change on a feature
  branch, and open a PR against `main`.
- Please keep contributions focused and small. If a change is large, consider
  opening an issue first to discuss the approach.
- Run `swift build` and `swift test` before opening a PR — all tests should pass.
- For material protocol or behaviour changes, update the docs and the
  on-hardware verification notes where relevant.
